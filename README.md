# 10 Games Website

A mobile-friendly website for Android and iOS users with:
- a showcase of 10 game cards
- a selector to filter cards
- playable game code for 10 lightweight mini-games in-browser
- Rock Paper Scissors now supports **1v1 mode** (same-device turn based)
- one-click **To Replit Web** link for each selected mini-game

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Mini-game flow

1. Choose a mini-game in the dropdown.
2. Press Start.
3. Follow status instructions (RPS offers Vs CPU or 1v1 mode).
4. Press Action each round.
5. Press Reset anytime to restart current game.
6. Click **To Replit Web** to open the selected game search on Replit in a new tab.
